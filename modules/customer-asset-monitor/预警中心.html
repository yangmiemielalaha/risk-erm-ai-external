预警等级判定标准（IV/HV）风险含义
红色 · 严重偏离 IV/HV > 1.6，或 IV/HV < 0.5 期权定价与已实现波动严重背离：偏高提示恐慌性溢价、买方成本畸高；偏低提示波动被严重低估，卖方尾部风险积聚
橙色 · 预警 1.4 < IV/HV ≤ 1.6，或 0.5 ≤ IV/HV < 0.65 波动率溢价明显异常，对冲成本与定价风险上升
黄色 · 关注 1.2 < IV/HV ≤ 1.4，或 0.65 ≤ IV/HV < 0.8 溢价偏离常态区间，需观察是否趋势性扩大
绿色 · 正常 0.8 ≤ IV/HV ≤ 1.2 隐含波动与已实现波动基本匹配，定价合理
注：IV 显著高于 HV 时，卖出期权（做市 / 备兑）具超额收益空间但需防尾部风险；IV 显著低于 HV 时，期权定价偏便宜，卖方承担波动低估风险、买方保护成本较低。新品种（CSR 未覆盖）以「—」列示，待数据补全后自动纳入评级。
指标口径说明： 涨跌幅 = 标的当日涨跌幅（%，红涨绿跌）；投机度 = 品种成交量 / 品种持仓量；成交量变化 = 当日成交量较上一交易日变动（%）；每日资金变化 = 当日持仓资金较上一交易日变动（%）；历史波动率 = 标的期货历史波动率（%）。 IV 现值 = 隐含波动率（%）；IV / PCR 分位数 = 该指标在历史区间中的百分位（0–100，越接近 100 当前水平越高）；IV/HV = IV 现值 ÷ 历史波动率，IV−HV 偏离单位为百分点（pp）。

指标口径说明

口径同《风险管理子公司驾驶舱》指标体系（快照 2026-08-04）
预警口径
  • 单指标超限：占用率 = 当前值 ÷ 授权限额；≥100% 超限（红）、≥80% 预警（橙）、≥70% 关注（黄）、其余正常（绿）。表格仅展示超限、预警、关注项，正常项不在表中列示。指标口径同《风险管理子公司驾驶舱》。
  • 趋势恶化：指标连续 3 个交易日同向恶化（业务当日盈亏——含场外、做市、期现业务——连续 3 日为负、敞口连续 3 日扩大、VAR 连续 3 日上升）即触发，触发即升级处置。
  • 组合恶化：同一交易日内多项指标同时恶化（如当日亏损＋敞口扩大），按组合规则 C1–C3 判定。敞口涵盖 Delta、Vega、Gamma 三个维度（金额口径：万元，正负号为方向），同方向绝对值较前一日扩大即视为「敞口扩大」（如 −100 → −200）。
  • 通知机制：点击「通知」将该条预警发送至期货公司与风险管理子公司相关人员
