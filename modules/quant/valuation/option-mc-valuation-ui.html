平台简介

衍智 OptionMind 是面向场外衍生品业务的期权智能估值平台，覆盖「交易确认书要素识别 → 收益结构代码比对 → 蒙特卡洛模拟估值 → 结果输出」的完整工作流。平台内置基础期权结构估值代码库（当前 7 类），并支持自定义收益结构扩展。

两条估值链路

链路一： 导入交易确认书→ 自动识别期权要素→ 结构比对→ 估值
链路二： 手动选择期权结构→ 录入合同参数→ 结构比对 / 自定义→ 估值
💡 有交易确认书时优先使用链路一（要素自动抽取，减少手工录入差错）；无确认书或做情景分析时使用链路二。

PDF、Word、Excel 及扫描件（OCR）。上传后由 NLP + 版面分析引擎自动抽取期权要素。

3. 结构比对与人工确认

⚠️ 差异确认是风控关键节点：确认操作会与估值记录一同留痕，可在「历史估值」中追溯。

链路二 · 手动选择结构

操作步骤

  1. 选择期权结构：点击结构卡片（雪球 / 香草 / 亚式 / 鲨鱼鳍 / 二元 / 区间累计 / 安全气囊），系统自动匹配代码库估值模型。
  2. 录入合同参数：参数表单随所选结构动态生成，只展示该模型需要的字段。
  3. 配置蒙特卡洛参数：也可关闭蒙特卡洛开关，改用解析解（仅香草、二元等适用）。
  4. 确认收益结构：库内模型的收益结构代码可直接预览；非库内结构选择「自定义结构」，在编辑器中手工编写收益结构代码及其他定制参数。
  5. 开始估值：修改过收益结构代码时会先弹出与库内模型的差异比对窗口，人工确认后执行。

结构代码库

代码库收录 7 类基础期权结构，每个结构包含：收益结构代码（PAYOFF_CODE）、合同参数模板、版本记录与自测状态。香草与二元期权含解析解，用于交叉验证蒙特卡洛引擎（自测偏差均 < 0.3%）。

提交收益结构代码→ 评审（待评审）→ 正式入库→ 纳入自测流水线

处于「待评审」状态的结构不可用于估值；评审通过后系统自动生成参数模板并开放估值权限。

常见问题

为什么收益结构不一致时必须人工确认？▶
收益结构是估值的核心输入，确认书条款与库内代码的任何差异（如票息 18.5% vs 18.0%）都会直接影响估值结果。人工确认确保估值口径与合约法律文本一致，确认记录会留痕可追溯。
什么情况下可以不用蒙特卡洛？▶
香草、二元等欧式简单结构存在 BS 框架下的解析解，关闭蒙特卡洛开关后可直接选用解析解估值，速度更快且无模拟误差。雪球、亚式、鲨鱼鳍等路径依赖结构必须使用蒙特卡洛。
估值结果可以复现吗？▶
可以。固定随机种子（默认 42）后，相同合约参数与市场参数下的每次估值结果完全一致。历史估值记录中保存了全部输入参数，支持一键复用重算。
置信区间过宽怎么办？▶
按优先级尝试：① 增加模拟路径数（误差约与 √N 成反比）；② 开启对偶变量 + 控制变量方差缩减；③ 检查波动率等输入参数是否异常。
自定义结构的代码有什么要求？▶
收益结构代码为 Python 函数 payoff(paths, params)，输入为模拟路径与合约参数，输出该路径下的收益金额。提交后进入评审流程，评审通过后纳入代码库与自测流水线。
库内模型的正确性如何保证？▶
库内含解析解的结构（香草、二元）以解析解为基准交叉验证，当前自测偏差均小于 0.3%；无解析解的结构通过提高路径数做收敛性复核，全部结构通过自测后方可标记「自测通过」。
